## 📌 Featured Project

### ⛪ CAMS — Church Attendance Management System

A full-stack attendance and member-management platform built using **.NET 10, ASP.NET Core MVC, Entity Framework Core 10, SQL Server, SignalR, Bootstrap, JavaScript, and Windows Forms**.

The system supports:

- Member registration and administrative approval
- OTP verification
- Configurable attendance events and schedules
- QR-based time-in and time-out
- Manual attendance
- Real-time attendance updates using SignalR
- Role-based authentication and authorization
- Fingerprint enrollment and attendance using a **Futronic FS88H**

👉 **[View the CAMS Repository](https://github.com/stevemeister05/CAMS)**
